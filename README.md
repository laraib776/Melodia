> [!NOTE]

## ✦ About Melodia

> **Melodia** is a music-themed website built with pure HTML, CSS, and JavaScript. It showcases popular artists, explores music genres and their histories, and connects music lovers to their favourite artists' Billboard profiles — all wrapped in a visually stunning, responsive design.
>
> Whether you're a casual listener or a hardcore music nerd, Melodia has something for you.

## ✨ Features

| 🌟 Feature | Details |

## 🚀 Getting Started

No installation required — Melodia runs straight in your browser!

### Option 1 — Open Directly

```bash
# Clone the repository:
git clone https://github.com/laraib776/Melodia.git

# Then simply open:
index.html
```

### Option 2 — Local Server

```bash
# Run from the project folder:
python -m http.server 8000

# Then visit:
http://localhost:8000
```

> 💡 You'll need a modern browser — Chrome, Firefox, Safari, or Edge all work perfectly.
